# Connect — караоке с друзьями в Telegram

Хозяин создаёт комнату и отправляет ссылку в чат. Друзья стучатся, хозяин их впускает (до 6 человек).
Каждый добавляет песню в общую очередь: караоке-видео с YouTube или свою минусовку. Один поёт,
остальные смотрят, слушают и шлют реакции.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
```

Откройте две вкладки (или телефон и компьютер в одной сети). Без `BOT_TOKEN` все заходят как гости по имени.
Камера и микрофон в браузере работают только на `localhost` или по HTTPS.

## Как устроено

| Часть | Файл | Что делает |
|---|---|---|
| Сервер | `server.js` | Статика, комнаты в памяти, одобрение входа, справедливая очередь (по песне от каждого за круг), сигналинг WebRTC, проверка подписи Telegram, избранное в `data/users.json` |
| Видеосвязь | `public/js/rtc.js` | Mesh WebRTC: каждый с каждым. Opus в стерео до 128 кбит/с, переподключение ICE |
| Голос исполнителя | `public/js/singer.js` | Микрофон без шумоподавления и автоусиления, компрессор, реверберация. Минусовка из файла подмешивается, и слушатели получают **один микс** |
| YouTube | `public/js/yt.js` | У каждого свой плеер. Позиция привязана к общему времени старта, у слушателей она сдвинута на измеренную задержку голоса (плюс ручная подстройка в «Звук») |
| Интерфейс | `public/js/app.js` | Экраны, очередь, реакции, тема и кнопки Telegram |

Режим без наушников: при пении включается эхоподавление, чтобы музыка из динамика не попала в микс дважды.
По умолчанию оно выключено: так голос звучит чище.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `BOT_TOKEN` | токен бота от @BotFather: включает проверку входа через Telegram (имя, аватар, избранное по Telegram ID) |
| `BOT_USERNAME`, `APP_SHORT_NAME` | чтобы «Позвать друзей» давал ссылку вида `t.me/<бот>/<app>?startapp=КОД` |
| `ALLOW_GUESTS` | `0` — пускать только из Telegram (по умолчанию гости по ссылке разрешены) |
| `ICE_SERVERS` | JSON со STUN/TURN, например `[{"urls":"turn:turn.example.com:3478","username":"u","credential":"p"}]` |
| `DATA_DIR` | куда сохранять профили и избранное |

## Подключение к Telegram

1. Разверните сервер по HTTPS (Render, Fly.io, Railway или VPS: есть `Dockerfile`).
2. В @BotFather: `/newbot`, затем `/newapp` → укажите URL сервера и короткое имя, например `karaoke`.
3. Задайте `BOT_TOKEN`, `BOT_USERNAME`, `APP_SHORT_NAME=karaoke`.
4. Ссылка на комнату — `https://t.me/<бот>/karaoke?startapp=КОД`. Mini App получает код из `start_param`.

## До релиза обязательно

- **TURN-сервер.** STUN хватает в домашних сетях, но через мобильных операторов и корпоративный Wi‑Fi часть звонков без TURN не соединится. Самый простой вариант — coturn на VPS или облачный TURN; данные указываются в `ICE_SERVERS`.
- **Проверка на реальных телефонах** (iOS и Android, разные сети): разрешения камеры и микрофона внутри Telegram, звук без нажатия, стабильность при шести участниках с камерами. В mesh исполнитель отправляет 5 потоков; если не потянет, нужен медиасервер (SFU, например LiveKit).
- **YouTube:** часть караоке-роликов запрещает встраивание. Приложение показывает ошибку и пропускает песню.
- Комнаты хранятся в памяти: перезапуск сервера их сбрасывает (профили и избранное сохраняются на диск).
